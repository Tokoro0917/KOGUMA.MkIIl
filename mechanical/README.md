# mechanical/

MK3(KOGUMA MkIIl)の機構データ。

| ファイル | 内容 |
|---|---|
| `KOGUMA.MK3.f3z` | Fusion 360 のアーカイブ(機体全体のアセンブリと、参照している部品の一式)。2026-10-17 追加 |

## 開き方

Fusion 360 で「ファイル → 開く → 自分のコンピュータから開く」で `KOGUMA.MK3.f3z` を選ぶ。参照している部品も一緒にクラウドのプロジェクトへ取り込まれる。

後継機 MK4 の設計(タイヤ径15mm、足回りは ToraNeko.Mk3 と同じ形)は別のリポジトリで進めている。
