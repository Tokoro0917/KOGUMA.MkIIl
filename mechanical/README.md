# mechanical/

MK3(KOGUMA MkIIl)の機構データ。

| ファイル | 内容 |
|---|---|
| `KOGUMA.MK3.f3z` | Fusion 360 のアーカイブ(機体全体のアセンブリと、参照している部品の一式)。2026-10-17 追加 |
| `KOGUMA.MK3_全体v2.step` | 機体全体(全体v2)を STEP で書き出したもの。Fusion 以外の CAD や、寸法・重さの計算に使う。2026-10-17 追加 |

## 開き方

Fusion 360 で「ファイル → 開く → 自分のコンピュータから開く」で `KOGUMA.MK3.f3z` を選ぶ。参照している部品も一緒にクラウドのプロジェクトへ取り込まれる。

後継機 MK4 の設計(タイヤ径15mm、足回りは ToraNeko.Mk3 と同じ形)は別のリポジトリで進めている。

## STEP から読んだ値(2026-10-17)

STEP の部品の位置・体積から計算した値。重さは材質の密度を仮定した見積もり(合計約77g、実測78g)。

| 項目 | 値 |
|---|---|
| タイヤ | 直径24mm、幅8mm。トレッド(左右のタイヤの中心の間)約60.6mm |
| ギア | ピニオン20T、スパー**71T**(歯先21.9mm)、エンコーダの歯車41T |
| 回転の慣性モーメント | 約450 g·cm²(足回り約190、底板約110、基板約55、電池約55) |

- `Define.h` の `GEARRATIO`(1.7073 = 70/41)は、スパーが71Tなら 71/41 = 1.7317 で、走った距離が約1.4%ずれる。実物の歯数を確かめる
- `Define.h` のトレッド(55mm)・タイヤ径(23.5mm)も、モデルの値(約60.6mm、24mm)と違う。実物で確かめる
