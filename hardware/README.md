アセンブリ一式(部品ごとに分かれている)。ヘッダの author / organization は空。

### 開き方

- **FreeCAD**(無料): File → Open でそのまま開く
- **Fusion 360**: アップロード → STEP として挿入
- 見るだけなら [3D Viewer](https://3dviewer.net/) 等のブラウザのビューアでも開ける(ローカルで読み込む形式のものを使う)

STEP はテキストだが42万行あって差分に意味がないので、`.gitattributes` で `-text -diff`(行末変換なし・差分なし)にしている。

## 部品構成

STEP の部品名(`PRODUCT`)から読めるもの。`(ミラー)` は左右対称の片側。

### 駆動

| 部品 | 備考 |
|---|---|
| 8520モータ | 8.5×20mm のコアレスモータ |
| スパーギアM0.3_T71 / 歯車M0.3T41 / 歯車M0.3T20 | モジュール0.3、歯数 71 / 41 / 20 |
| LF-630(内輪・外輪・保持器・ボール) | フランジ付きベアリング。玉まで作られている |
| ベアリング(D6 d3) | 外径6 / 内径3 |
| モーターマウントv2、エンコーダギアマウント、足回りv2 | |

歯数から考えられる減速比は **41/20 = 2.05** または **71/20 = 3.55**。今の機体は 1.7073 で、`docs/next_robot.md`「2. モーターとギア比」で「2.0 くらいに上げると立ち上がりの角加速度と低い速度の加速が1割ほど上がる」と見積もった値に 2.05 が合う。ただしどれが実際の減速段かは部品名だけでは決まらないので、CAD で確認が必要。
